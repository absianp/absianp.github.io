옵시디언(Obsidian)을 처음 설치하면 하얀 빈 화면과 검은 바탕 외에는 아무것도 보이지 않아 많은 분들이 당황하곤 합니다. 자유도가 무한에 가깝다는 점은 옵시디언의 가장 큰 장점이지만, **초기에 폴더 구조와 필수 설정을 제대로 잡아두지 않으면 몇 주 지나지 않아 노트가 뒤엉켜 포기**하게 되는 가장 큰 원인이 되기도 합니다.

이번 2편에서는 **Mac, Windows, Linux 각 운영체제별 최적의 설치 위치와 단축키 팁**, 그리고 10년 이상 지속 가능한 **PARA 기반 폴더 아키텍처 및 필수 플러그인 세팅법**을 한 번에 정리해 드립니다.

---

## 1. 운영체제(OS)별 최적의 보관함(Vault) 위치 전략

옵시디언에서 하나의 작업 공간을 **'보관함(Vault)'**이라고 부릅니다. 이 보관함은 컴퓨터 하드디스크의 일반 폴더와 동일하므로, 어디에 만드느냐에 따라 동기화 편의성과 안정성이 결정됩니다.

### 🍎 macOS 환경
* **권장 경로**: `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/` (iCloud Drive 내부)
* **장점**: 별도의 유료 서비스 없이도 **아이폰(iPhone), 아이패드(iPad)의 옵시디언 모바일 앱과 완벽한 무료 실시간 동기화**가 지원됩니다.
* **주의사항**: Mac의 [저장 공간 최적화] 기능이 켜져 있으면 오래된 마크다운 파일이 클라우드로만 올라가 로컬에서 누락될 수 있으므로, 옵시디언 폴더는 항상 '다운로드 유지' 상태로 설정해야 합니다.

### 🪟 Windows 환경
* **권장 경로**: `C:\Users\{사용자명}\Documents\ObsidianVault`
* **동기화 팁**: OneDrive 폴더 내부에 생성하면 다른 Windows PC와 실시간 공유가 가능합니다. 만약 안드로이드(Android) 스마트폰과 동기화하고 싶다면 오픈소스 플러그인인 **`Remotely Save`** (OneDrive/Dropbox 연동)를 사용하는 것이 가장 깔끔합니다.

### 🐧 Linux 환경 (Ubuntu, Fedora, Arch 등)
* **권장 패키지**: Flatpak 또는 AppImage
* **권장 경로**: `~/Documents/Obsidian/`
* **동기화 팁**: 리눅스 파워 유저에게는 **`Obsidian Git`** 플러그인이 최선의 선택입니다. 10분마다 자동으로 커밋 & 푸시하여 GitHub 프라이빗 저장소에 무제한 버전 히스토리 백업을 구축할 수 있습니다.

## 2. 평생 정리 걱정 없는 'PARA + 메타' 폴더 아키텍처

폴더를 주제별(수학, 경제, 프로그래밍, 일기...)로 잘게 쪼개다 보면 "이 메모는 어디에 넣어야 하지?"라는 결정 장애가 발생합니다. 세계적인 생산성 전문가 티아고 포르테(Tiago Forte)의 **PARA 프레임워크**를 적용하면 모든 정보가 명확한 목적을 갖게 됩니다.

```text
📁 My-Second-Brain (Vault Root)
├── 📁 00_Meta/                 # 템플릿, 대시보드, 시스템 관리 문서
│   ├── 📁 Templates/           # 일일 노트, 독서록, AI 프롬프트 템플릿
│   └── 🏠 Dashboard.md         # Dataview 기반 통합 현황판
├── 📁 01_Projects/             # 마감 기한과 목표가 있는 진행 중인 일 (1~3개월)
│   ├── 2026_블로그_애드센스_승인/
│   └── 유튜브_영상_시나리오_기획/
├── 📁 02_Areas/                # 지속적으로 관리하는 삶의 영역 (마감 없음)
│   ├── 건강_및_운동/
│   ├── 자산관리_및_재테크/
│   └── 개발_및_기술스택/
├── 📁 03_Resources/            # 언제든 참고할 수 있는 영구 지식 베이스
│   ├── 📚_독서노트/
│   ├── 💻_파이썬_스니펫/
│   └── 🤖_AI_프롬프트_치트시트/
├── 📁 04_Archives/             # 완료되거나 중단된 프로젝트 영구 보관소
└── 📁 assets/                  # 이미지, PDF 등 첨부파일 전용 격리 폴더
```

> 💡 **핵심 팁**: 폴더 이름 앞에 `00_`, `01_`과 같은 번호를 붙여두면 파일 탐색기에서 항상 최상단에 원하는 우선순위대로 단정하게 고정 정렬됩니다.

## 3. 설치 즉시 바꿔야 하는 3가지 필수 코어 설정

옵시디언 기본 설정을 그대로 사용하면 이미지가 루트 디렉터리에 난잡하게 흩어지고 링크가 깨질 수 있습니다. 아래 3가지는 필수적으로 변경해야 합니다.

1. **첨부파일 저장 위치 격리**:
   * `[설정]` ➡️ `[파일 및 링크]` ➡️ **기본적으로 새 첨부파일이 저장되는 위치**
   * 설정값을 **`아래 지정된 하위 폴더`**로 바꾸고, 폴더 이름에 **`assets`**를 입력합니다.
   * 이제 노트에 캡처 이미지를 붙여넣어도 메인 폴더가 지저분해지지 않고 `assets` 폴더로 자동 수납됩니다.
2. **새 링크의 형식 통일**:
   * `[설정]` ➡️ `[파일 및 링크]` ➡️ **새 링크의 형식**을 **`가장 짧은 경로(Shortest path)`**로 설정합니다.
   * 파일 위치를 다른 폴더로 이동해도 `[[문서명]]` 링크가 깨지지 않고 자동으로 유지됩니다.
3. **삭제 파일 휴지통 보관**:
   * `[설정]` ➡️ `[파일 및 링크]` ➡️ **삭제된 파일**을 **`시스템 휴지통으로 이동`**으로 설정하여 실수로 노트를 삭제했을 때 즉시 복구할 수 있도록 안전장치를 마련합니다.

## 4. 생산성을 300% 올려주는 필수 플러그인 5선

옵시디언의 진정한 마법은 커뮤니티 플러그인에서 시작됩니다. 수천 개의 플러그인 중 기본적으로 반드시 깔아두어야 할 베스트 5입니다:

1. **Dataview (데이터뷰)**:
   * 마크다운 노트를 SQL 데이터베이스처럼 쿼리(Query)할 수 있게 해주는 옵시디언 최고의 플러그인입니다. "이번 주에 작성한 읽을거리 목록", "진행 중인 프로젝트 현황"을 자동 집계 대시보드로 만들어줍니다.
2. **Omnisearch (옴니서치)**:
   * 일반 텍스트뿐만 아니라 노트에 삽입된 PDF, 이미지 안의 글자(OCR)까지 오차 없는 인공지능형 유사도 검색으로 즉시 찾아냅니다.
3. **Advanced Tables (고급 표 편집)**:
   * 마크다운의 까다로운 표 작성을 엑셀처럼 탭(Tab) 키와 엔터(Enter) 키만으로 열과 행을 자동 정렬해 줍니다.
4. **Editing Toolbar (편집 툴바)**:
   * MS 워드나 노션처럼 상단에 글자 굵기, 색상, 형광펜, 정렬 버튼 툴바를 제공하여 마크다운 문법이 낯선 초보자도 손쉽게 서식을 지정할 수 있습니다.
5. **Paste URL into Selection**:
   * 텍스트를 드래그한 상태에서 복사한 링크를 `Ctrl+V` (또는 `Cmd+V`)로 붙여넣으면 자동으로 `[텍스트](URL)` 마크다운 링크로 변환해 주는 필수 편의 플러그인입니다.
