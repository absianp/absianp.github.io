많은 분들이 챗GPT(ChatGPT)나 클로드(Claude)를 사용하면서도 늘 아쉬움을 느낍니다. "내가 몇 달 전에 써둔 그 메모 내용과 연관 지어서 답변해 줄 수는 없을까?", "회사 기밀이나 내밀한 개인 일기장을 외부 서버에 올리지 않고 안전하게 요약할 수는 없을까?"

이 고민을 단번에 해결해 주는 기술이 바로 **옵시디언과 로컬 AI(RAG)의 결합**입니다.

이번 3편에서는 내 컴퓨터에 저장된 마크다운 노트들을 스스로 학습하여 유기적인 연결고리를 찾아주는 **`Smart Connections`** 플러그인과, 단 1원의 API 비용도 들지 않는 **`Ollama 무료 로컬 LLM`**을 연동하여 **100% 프라이버시가 보장되는 나만의 개인화 AI 뇌**를 구축하는 실전 단계를 안내해 드립니다.

---

## 1. 옵시디언 AI 아키텍처의 원리 (RAG란?)

일반적인 챗봇과 옵시디언 AI의 가장 큰 차이는 **검색 증강 생성(RAG, Retrieval-Augmented Generation)**에 있습니다.

```text
[내 옵시디언 노트들] ──(벡터 임베딩)──> [Smart Connections 지식 DB]
                                                  │
[사용자 질문] ──("작년에 정리한 파이썬 팁 찾아줘")───────┴──> [Ollama 로컬 AI] ──> [내 노트를 인용한 정확한 답변!]
```

1. **임베딩(Embedding)**: 내가 작성한 수백, 수천 개의 노트를 의미 단위의 숫자 벡터로 변환하여 저장합니다.
2. **검색(Retrieval)**: 내가 질문을 던지면, 질문과 가장 의미가 유사한 내 과거 노트를 0.1초 만에 끄집어냅니다.
3. **생성(Generation)**: 내 노트를 프롬프트에 얹어 로컬 AI에게 전달하고, AI는 **오직 내 노트를 바탕으로 정밀한 요약과 통찰을 제공**합니다.

## 2. 1단계: 컴퓨터에 무료 로컬 AI 엔진(Ollama) 설치하기

[Ollama(올라마)](https://ollama.com/)는 Mac, Windows, Linux 어디서나 터미널 명령어 한 줄로 최신 오픈소스 AI 모델을 무료로 구동해 주는 최고의 오픈소스 도구입니다.

### ① Ollama 다운로드 및 설치
* [Ollama 공식 홈페이지](https://ollama.com/)에서 본인의 운영체제에 맞는 설치 파일을 받아 설치합니다.
* 설치가 완료되면 백그라운드 트레이에 귀여운 라마 아이콘이 상주하며 준비 상태가 됩니다.

### ② 고성능 경량 한국어 지원 모델 다운로드
터미널(Mac: Terminal, Windows: PowerShell)을 열고 아래 명령어를 입력합니다.

```bash
# 2026년 기준 가장 추천하는 가성비 모델: Qwen 2.5 (한국어 이해도 최상)
ollama run qwen2.5:7b

# 만약 구형 노트북이거나 사양이 낮다면 3B 초경량 모델 추천:
ollama run llama3.2:3b
```
다운로드가 완료되면 터미널에서 즉시 대화가 가능해집니다. `Ctrl+D`를 눌러 터미널을 빠져나옵니다.

## 3. 2단계: 옵시디언에 Smart Connections 플러그인 설치

이제 옵시디언 내부에서 이 AI 엔진과 내 노트를 이어줄 다리를 놓아야 합니다.

1. 옵시디언 실행 후 좌측 하단 `[설정(⚙️)]` ➡️ `[커뮤니티 플러그인]`으로 이동합니다.
2. `[탐색]` 버튼을 누르고 **`Smart Connections`**를 검색하여 설치 및 활성화합니다.
3. 활성화 후 좌측 설정 사이드바에 생긴 `[Smart Connections]` 탭을 클릭합니다.

---

## 4. 3단계: 로컬 AI & 임베딩 설정 (비용 0원 세팅)

Smart Connections 설정 화면에서 외부 유료 API(OpenAI 등) 대신 **로컬 무료 엔진**을 선택해 줍니다:

### ① 임베딩 모델 (Embedding Model) 설정
* **Embedding Provider**: `Smart Connections (Local)` 또는 `Ollama` 선택
* **Model**: `bge-micro-v2` (또는 `nomic-embed-text`)
* 설정 후 하단의 **`[Transform / Embed Notes]`** 버튼을 누르면, 내 보관함의 모든 노트를 분석하여 로컬 벡터 인덱스를 구축합니다. (노트 1,000개 기준 약 1~2분 소요)

### ② 대화 모델 (Chat Model) 설정
* **Chat Model Provider**: **`Ollama`** 선택
* **Ollama Server URL**: `http://localhost:11434` (기본값)
* **Model Name**: 우리가 터미널에서 다운받은 **`qwen2.5:7b`** (또는 `llama3.2:3b`) 입력

## 5. 실전 활용: 내 노트와 대화하는 2가지 방법

모든 세팅이 완료되면 옵시디언 우측 패널에 새로운 아이콘 2개가 나타납니다:

### 💬 1. Smart Chat (내 노트 기반 질의응답)
우측 패널의 대화창에 자연어로 질문을 던져보세요:
* *"내가 최근 3개월간 독서록에 적어둔 '생산성 관련 습관'들을 3가지로 종합 요약해줘."*
* *"지난달에 작성한 블로그 부업 아이디어 노트들 중에서 구글 애드센스와 연관된 항목만 뽑아줘."*

AI는 내 노트의 실제 제목과 줄 번호를 링크(`[[파일명]]`) 형태로 달아주면서 완벽하게 요약해 줍니다. 엉뚱한 환각(Hallucination) 없이 내 실제 기록만을 기반으로 답변하므로 신뢰도가 100%입니다.

### 🔗 2. Smart View (연관 노트 자동 탐색기)
지금 열려 있는 노트와 가장 의미적으로 가까운 과거의 다른 노트를 우측 창에 실시간으로 순위를 매겨 추천해 줍니다.
* 예를 들어 오늘 *"파이썬 자동화 스크립트 작성"*이라는 새 노트를 쓰면, 6개월 전에 작성했던 *"데이터 분석 기초"*나 *"크롤링 주의사항"* 노트가 오른쪽에 자동으로 떠오릅니다.
* 잊고 있던 과거의 지식이 현재의 생각과 저절로 맞물리며 폭발적인 아이디어 확장을 경험하게 됩니다.

이제 여러분의 컴퓨터 안에는 **외부에 단 하나의 단어도 전송하지 않으면서, 내가 평생 작성한 모든 지식을 기억하고 보조해 주는 완벽한 오프라인 AI 파트너**가 생겼습니다.
