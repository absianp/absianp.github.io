다운로드 폴더를 정리할 때는 **같은 이름과 같은 내용을 구분하고, 기존 파일을 덮어쓰지 않으며, 중복 원본도 자동 삭제하지 않는 기준**이 필요합니다. 아래 코드는 이 기준에 파일 상태 재검사를 더한 예제입니다.

운영자가 제공한 비교 검증 자료에서는 개선 예제가 일부 변경을 감지해 원본 경로를 보존했습니다. 다만 **마지막 검사 뒤 발생한 쓰기는 막지 못했고, 변경된 내용을 목적지에 남긴 채 `moved`를 기록했습니다.** 다운로드·편집·동기화를 멈춘 폴더에서 사용해야 합니다.

## 충돌과 중복을 처리하는 기준

| 상황 | 처리 |
| --- | --- |
| 목적지 이름이 비어 있음 | 해당 이름으로 이동 시도 |
| 같은 이름·같은 내용 | `duplicate_kept`를 기록하고 원본 유지 |
| 같은 이름·다른 내용 | `report (1).pdf`처럼 번호 후보 확인 |
| 목적지 이름이 디렉터리나 심볼릭 링크 | 사용 중인 이름으로 보고 다음 후보 확인 |
| 이름 확인 후 다른 파일이 목적지를 선점 | 링크 생성의 이름 충돌을 처리하고 후보 재선택 |
| 이름은 다르지만 내용이 같음 | 별도 파일로 분류 |

내용 비교는 크기를 확인한 뒤 **1 MiB씩 바이트를 읽어 비교**합니다. 검증 자료의 SHA256은 실험 전후 바이트 기록에 쓰였으며, 예제의 중복 판정 방식은 해시 비교가 아닙니다. 비어 있는 후보를 먼저 찾으면 그 이름을 사용하므로 뒤쪽 번호나 다른 이름까지 조사하는 전체 중복 제거 기능은 없습니다.

실제 반영은 `os.link()`로 목적지 하드 링크를 만든 뒤 원본 경로를 삭제합니다. 두 이름은 같은 파일을 가리킵니다. Linux `link(2)` 문서는 이미 존재하는 목적지를 덮어쓰지 않으며 파일시스템을 가로질러 하드 링크를 만들 수 없다고 명시합니다. [os.link 문서](https://docs.python.org/3.11/library/os.html#os.link), [Linux link(2) 문서](https://man7.org/linux/man-pages/man2/link.2.html)

개선 예제는 파일명의 확장자 목록에 `.part`, `.partial`, `.crdownload`, `.download`, `.tmp`가 있으면 건너뜁니다. 따라서 `download.part.pdf`도 제외합니다. 기본값에서는 수정 후 30초가 지나지 않은 파일을 `skipped_recent`로 남깁니다. **스크립트가 30초 동안 기다리는 기능이 아니라, 이번 실행에서 건너뛰는 조건**입니다. 두 조건 모두 다운로드 완료나 파일 형식의 유효성을 판정하지 않습니다.

대부분의 비교 테스트는 다른 동작을 분리해서 확인하려고 대기 조건을 0초로 설정했고, 최근 파일 시나리오는 30초로 실행했습니다. 실행 시간 기록은 처리 성능 벤치마크가 아닙니다.

**EXDEV·EACCES·원본 삭제 실패는 해당 호출에 오류를 주입한 검증**입니다. 실제 다른 볼륨으로 옮기거나 계정 권한을 제한한 실험이 아닙니다. `.pdf`와 이미지 확장자의 시험 파일도 합성 바이트를 사용했으므로 PDF·이미지 유효성 검증으로 해석하면 안 됩니다.

## 실행 코드

다음은 제공된 검증 대상 `organize_downloads_checked.py` 전체입니다. 정리 대상 폴더 밖에 같은 파일명으로 저장하세요. 외부 패키지는 필요하지 않습니다.

추가된 상태 검사는 파일 식별자·크기·시각 등의 변화를 확인합니다. 후보 탐색과 충돌 재시도에는 제한이 있고, 로그 쓰기에 실패하면 중단합니다. 이 검사는 파일 잠금이나 다른 프로세스의 경로 교체를 막는 보안 경계가 아닙니다.

```python
"""Conservative, nonrecursive organizer for a quiescent personal test directory.

Default: preview. Apply uses link-then-unlink on the SAME filesystem. This is not
an atomic move, a download-completion detector, a lock against writers, or a
security boundary against another process replacing paths. Stop downloads,
editors, and synchronization first; test a disposable copy before actual use.
"""
import argparse
from dataclasses import dataclass
from datetime import datetime, timezone
import json
import math
import os
from pathlib import Path
import stat
import time

RULES = {'.pdf': 'documents', '.docx': 'documents', '.txt': 'documents',
         '.jpg': 'images', '.jpeg': 'images', '.png': 'images', '.zip': 'archives'}
PARTIAL_SUFFIXES = {'.part', '.partial', '.crdownload', '.download', '.tmp'}
CHUNK = 1024 * 1024


class FileChanged(OSError):
    """The observed file state changed; do not remove its source path."""


class JournalError(RuntimeError):
    pass


@dataclass(frozen=True)
class Version:
    dev: int
    ino: int
    mode: int
    size: int
    mtime_ns: int
    ctime_ns: int

    @classmethod
    def of(cls, info):
        return cls(info.st_dev, info.st_ino, info.st_mode, info.st_size,
                   info.st_mtime_ns, info.st_ctime_ns)

    def after_own_link(self, other):
        # Creating a hard link changes ctime. It must not itself count as a write.
        return (self.dev, self.ino, self.mode, self.size, self.mtime_ns) == (
            other.dev, other.ino, other.mode, other.size, other.mtime_ns)


def snapshot(path):
    info = path.lstat()  # Never follows the final path component.
    if not stat.S_ISREG(info.st_mode):
        raise FileChanged('not a regular file')
    return Version.of(info)


def ensure_unchanged(path, expected, *, own_link=False):
    current = snapshot(path)
    if not (expected.after_own_link(current) if own_link else current == expected):
        raise FileChanged('file identity, size, mode, or timestamps changed')
    return current


def same_content(src, dst, expected):
    """Compare bytes with before/after checks; do not assume a hash is proof."""
    if dst.is_symlink() or not dst.is_file():
        return False
    ensure_unchanged(src, expected)
    other = snapshot(dst)
    if expected.size != other.size:
        return False
    flags = os.O_RDONLY | getattr(os, 'O_NOFOLLOW', 0)
    # O_NOFOLLOW is an extra POSIX protection, not a portable concurrency guarantee.
    with os.fdopen(os.open(src, flags), 'rb') as left, os.fdopen(os.open(dst, flags), 'rb') as right:
        if Version.of(os.fstat(left.fileno())) != expected or Version.of(os.fstat(right.fileno())) != other:
            raise FileChanged('file changed before opening for comparison')
        equal = True
        while True:
            a, b = left.read(CHUNK), right.read(CHUNK)
            if a != b:
                equal = False
                break
            if not a:
                break
        if Version.of(os.fstat(left.fileno())) != expected or Version.of(os.fstat(right.fileno())) != other:
            raise FileChanged('file changed during comparison')
    ensure_unchanged(src, expected)
    ensure_unchanged(dst, other)
    return equal


def choose_destination(src, folder, expected, *, max_candidates=1000):
    for number in range(max_candidates):
        name = src.name if number == 0 else f'{src.stem} ({number}){src.suffix}'
        destination = folder / name
        if not os.path.lexists(destination):
            return 'move', destination
        if same_content(src, destination, expected):
            return 'duplicate', destination
    raise OSError('destination candidate limit reached')


def emit(events, journal, event, src, dst=None, detail=None):
    row = {'time': datetime.now(timezone.utc).isoformat(), 'event': event,
           'src': str(src), 'dst': str(dst) if dst else None, 'detail': detail}
    if journal is not None:
        try:
            journal.write(json.dumps(row, ensure_ascii=False) + '\n')
            journal.flush()
            os.fsync(journal.fileno())
        except OSError as exc:
            raise JournalError('Journal failed; stop and inspect both paths.') from exc
    events.append(row)


def run(root, *, apply=False, journal=None, min_age_seconds=30, max_candidates=1000):
    """Return observed events. Preview creates no files, directories, or journal.

    min_age_seconds is a waiting heuristic, not evidence that a file is complete.
    In apply mode the caller supplies an exclusively created writable journal.
    """
    if isinstance(min_age_seconds, bool) or not math.isfinite(min_age_seconds) or min_age_seconds < 0:
        raise ValueError('min_age_seconds must be a finite nonnegative number')
    if type(max_candidates) is not int or max_candidates < 1:
        raise ValueError('max_candidates must be a positive integer')
    if apply and journal is None:
        raise ValueError('apply requires an open journal')
    if not apply and journal is not None:
        raise ValueError('preview does not write a journal')
    root = Path(root).expanduser()
    if root.is_symlink():
        raise ValueError('root itself must not be a symbolic link')
    root = root.resolve(strict=True)
    if not root.is_dir():
        raise NotADirectoryError(str(root))
    events = []
    for src in sorted(root.iterdir(), key=lambda p: p.name):
        dst = None
        try:
            if src.is_symlink() or not src.is_file():
                continue
            if any(s.lower() in PARTIAL_SUFFIXES for s in src.suffixes):
                emit(events, journal, 'skipped_partial_name', src)
                continue
            group = RULES.get(src.suffix.lower())
            if group is None:
                continue
            expected = snapshot(src)
            if time.time_ns() - expected.mtime_ns < min_age_seconds * 1_000_000_000:
                emit(events, journal, 'skipped_recent', src)
                continue
            folder = root / group
            if folder.is_symlink():
                raise OSError('classification directory is a symbolic link')
            if folder.exists() and not folder.is_dir():
                raise NotADirectoryError(str(folder))
            if apply:
                folder.mkdir(exist_ok=True)
            for attempt in range(max_candidates):
                ensure_unchanged(src, expected)
                action, dst = choose_destination(src, folder, expected, max_candidates=max_candidates)
                if not apply:
                    emit(events, None, 'preview_' + action, src, dst)
                    break
                if action == 'duplicate':
                    emit(events, journal, 'duplicate_kept', src, dst)
                    break
                emit(events, journal, 'intent', src, dst)
                ensure_unchanged(src, expected)
                try:
                    os.link(src, dst, follow_symlinks=False)
                except FileExistsError:
                    continue  # Re-evaluate names; never overwrite the competing file.
                emit(events, journal, 'linked', src, dst)
                ensure_unchanged(dst, expected, own_link=True)
                ensure_unchanged(src, expected, own_link=True)
                # There is still a check/unlink race. Do not use in a hostile/shared directory.
                src.unlink()
                emit(events, journal, 'moved', src, dst)
                break
            else:
                raise OSError('repeated destination contention; source kept')
        except FileChanged as exc:
            emit(events, journal, 'changed_kept', src, dst, str(exc))
        except OSError as exc:
            emit(events, journal, 'error', src, dst, f'{type(exc).__name__}: {exc}')
    return events


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('root', type=Path)
    parser.add_argument('--apply', action='store_true')
    parser.add_argument('--min-age-seconds', type=float, default=30)
    args = parser.parse_args()
    if args.apply:
        if args.root.is_symlink():
            parser.error('root itself must not be a symbolic link')
        root = args.root.expanduser().resolve(strict=True)
        stamp = datetime.now(timezone.utc).strftime('%Y%m%dT%H%M%S%fZ')
        with (root / f'.organize-{stamp}.jsonl').open('x', encoding='utf-8') as journal:
            events = run(root, apply=True, journal=journal, min_age_seconds=args.min_age_seconds)
    else:
        events = run(args.root, min_age_seconds=args.min_age_seconds)
    for event in events:
        print(json.dumps(event, ensure_ascii=False))


if __name__ == '__main__':
    main()
```

## 실행 방법

먼저 다운로드·편집·동기화를 멈추고, 폐기 가능한 복사본으로 `Downloads-test` 폴더를 준비합니다. 아래 구조에서 두 `report.pdf`에는 서로 다른 내용을, 두 `same.txt`에는 같은 내용을 넣으세요. 이 절차는 충돌 동작을 확인하기 위한 예시이며 문서 형식 검사는 아닙니다.

```text
Downloads-test/
├── report.pdf
├── same.txt
└── documents/
    ├── report.pdf
    └── same.txt
```

스크립트와 `Downloads-test`가 있는 상위 폴더에서 버전을 확인하고 미리보기를 실행합니다.

```bash
python3 --version
python3 organize_downloads_checked.py "Downloads-test"
```

출력은 한 줄씩 JSON 이벤트입니다. 파일 수정 후 30초가 지나지 않았다면 `skipped_recent`가 나올 수 있습니다. 쓰기가 멈춘 상태에서 30초가 지난 뒤 다시 실행하세요. 이 대기는 실습 조건을 맞추기 위한 것이며 완료 여부를 증명하지 않습니다.

위 폴더가 그대로 유지되고 파일이 대기 조건을 충족한다면, 예상 결과는 `report.pdf`에 대한 `preview_move`와 `documents/report (1).pdf` 목적지, `same.txt`에 대한 `preview_duplicate`입니다. 미리보기 결과를 확인한 뒤 적용합니다.

```bash
python3 organize_downloads_checked.py "Downloads-test" --apply
```

예상 결과는 기존 `documents/report.pdf` 보존, 새 내용의 `documents/report (1).pdf` 생성, 두 `same.txt` 유지입니다. 실제 파일 내용과 로그를 대조하세요. 미리보기 이후 파일 상태가 달라지면 적용 시 이름과 중복 판정도 달라질 수 있습니다.

`--min-age-seconds 0`은 최근 수정 파일을 제외하는 조건을 해제합니다. 제공된 비교 검증에서도 주로 이 설정을 사용했지만, 실제 다운로드가 끝났다는 의미로 사용해서는 안 됩니다.

## 한계와 복구

실제 적용 시 입력 폴더에 실행별 `.organize-날짜.jsonl` 로그를 만듭니다. 이벤트는 다음처럼 읽습니다.

| 이벤트 | 의미 |
| --- | --- |
| `preview_move`, `preview_duplicate` | 미리보기에서 선택한 처리 |
| `skipped_partial_name` | 알려진 임시 확장자 이름 때문에 건너뜀 |
| `skipped_recent` | 수정 시각이 대기 조건을 충족하지 않아 건너뜀 |
| `intent` | 해당 목적지로 링크 생성을 시도하기 전 기록 |
| `linked` | 링크 생성 성공. 원본 경로도 남아 있을 수 있음 |
| `moved` | 원본 경로 삭제 후 기록. 다운로드 완료나 내용 불변을 뜻하지 않음 |
| `duplicate_kept` | 충돌 파일과 내용이 같아 원본 유지 |
| `changed_kept` | 상태 변화를 감지해 원본 경로 삭제를 피함. 이미 링크가 생겼을 수 있음 |
| `error` | 파일 처리 중 오류. 실제 두 경로 상태를 확인해야 함 |

하드 링크 생성과 원본 경로 삭제는 **별개의 작업**입니다. 원본 삭제는 파일 경로를 제거하는 동작이며, 중간에 실패하면 같은 파일을 가리키는 두 이름이 남을 수 있습니다. [os.unlink 문서](https://docs.python.org/3.11/library/os.html#os.unlink), [Linux link(2) 문서](https://man7.org/linux/man-pages/man2/link.2.html)

두 경로가 남았다면 다음 순서로 확인하세요.

1. 관련 다운로드·편집·동기화 작업을 중지합니다.
2. 로그의 마지막 `src`와 `dst`가 실제로 존재하는지 확인합니다.
3. 두 경로가 같은 파일을 가리키는지와 현재 내용을 확인합니다. 같은 하드 링크라면 한쪽 편집이 다른 경로에도 반영됩니다.
4. 보존할 데이터를 별도로 확보한 뒤 필요한 경로만 남깁니다. 로그만 근거로 자동 삭제하거나 되돌리지 마세요.

원본 삭제 실패를 주입한 실험에서는 재실행해도 `duplicate_kept`가 기록될 뿐, 남은 원본 경로를 자동 삭제하지 않았습니다. 또한 로그와 파일 작업은 하나의 트랜잭션이 아니므로 원본 삭제 뒤 로그 쓰기가 실패하면 `moved`가 없더라도 원본 경로가 이미 사라졌을 수 있습니다.

오류가 났다는 이유만으로 목적지가 없다고 단정해서도 안 됩니다. Linux 문서는 NFS에서 링크 생성이 이루어진 뒤에도 실패가 반환될 수 있다고 설명합니다. 네트워크 저장소는 이번 실행 검증 범위 밖입니다. [Linux link(2)의 NFS 주의사항](https://man7.org/linux/man-pages/man2/link.2.html)

마지막 상태 검사와 원본 경로 삭제 사이에도 쓰기나 경로 변경이 가능합니다. 제공된 변경 주입 시나리오에서 이 한계가 관측되었습니다. 이 코드는 백업, 동시 쓰기 차단, 파일 형식 검사, 다운로드 완료 판정을 제공하지 않으며 전원 장애 후 데이터 보존도 검증하지 않았습니다.
