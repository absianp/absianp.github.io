매일 혹은 매주 반복되는 엑셀 취합과 보고 메일 발송 업무는 규칙이 명확하다면 파이썬 스크립트로 자동화할 수 있습니다. 본 글에서는 여러 폴더에 흩어진 엑셀 파일을 취합해 결측치를 정제하고, 요약 보고서를 이메일로 자동 전송한 뒤 OS 스케줄러로 무인 실행하는 기본 파이프라인을 다룹니다.

### 2. 다중 엑셀 파일 취합 및 결측치 정제

*(안내: 아래 코드는 로직 예시이며, 사용자 환경의 파일 구조에 따라 경로와 컬럼명을 수정해야 합니다. 본 환경 내 직접 실행 검증은 미실시되었습니다.)*

동일한 서식을 가진 여러 지점의 엑셀 파일을 하나의 데이터프레임으로 병합하고, 필수 값 누락 행을 처리하는 로직입니다.

```python
import os
import glob
import pandas as pd

def aggregate_excels(input_dir: str, output_file: str) -> pd.DataFrame:
    # 지정 디렉터리 내 모든 xlsx 파일 경로 검색
    file_list = glob.glob(os.path.join(input_dir, "*.xlsx"))
    if not file_list:
        raise FileNotFoundError(f"{input_dir} 경로에 엑셀 파일이 존재하지 않습니다.")

    dfs = []
    for file_path in file_list:
        # 임시 파일(~$) 제외
        if os.path.basename(file_path).startswith("~"):
            continue
        
        # 파일 읽기 (openpyxl 엔진 사용)
        df = pd.read_excel(file_path, engine="openpyxl")
        df["출처파일"] = os.path.basename(file_path)
        dfs.append(df)

    # 데이터 병합
    combined_df = pd.concat(dfs, ignore_index=True)

    # 정제: 필수 식별값(예: '주문번호') 결측 행 제거 및 수량 결측치 0 대체
    if "주문번호" in combined_df.columns:
        combined_df = combined_df.dropna(subset=["주문번호"])
    if "수량" in combined_df.columns:
        combined_df["수량"] = combined_df["수량"].fillna(0)

    # 결과 저장
    combined_df.to_excel(output_file, index=False, engine="openpyxl")
    return combined_df
```

* **입력 조건**: `input_dir` 내 동일한 컬럼 구조를 가진 `.xlsx` 파일들
* **예상 결과**: `output_file`로 지정된 경로에 정제·병합된 엑셀 파일 생성 및 데이터프레임 반환

### 3. 예외 처리(try-except)와 로그 기록

무인 실행 환경에서는 콘솔 출력 대신 로그 파일에 성공 및 실패 내역을 남겨야 사후 원인 파악이 가능합니다.

```python
import logging

# 로그 설정
logging.basicConfig(
    filename="pipeline.log",
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    encoding="utf-8"
)

def run_pipeline():
    logging.info("파이프라인 실행 시작")
    try:
        input_path = "./data/incoming"
        output_path = "./data/report_aggregated.xlsx"
        
        df = aggregate_excels(input_path, output_path)
        logging.info(f"데이터 취합 성공: 총 {len(df)}건 처리 완료")
        
    except KeyError as e:
        logging.error(f"필수 컬럼 누락 오류 발생: {e}")
    except FileNotFoundError as e:
        logging.warning(f"파일 탐색 실패: {e}")
    except Exception as e:
        logging.critical(f"예상치 못한 시스템 예외: {e}", exc_info=True)
    finally:
        logging.info("파이프라인 실행 종료")
```

### 4. 서식 기반 요약 보고서 이메일 발송

파이썬 표준 모듈인 `smtplib`와 `email`을 사용해 요약 내용(HTML 본문)과 결과 파일을 첨부해 발송합니다.

*(안내: 실행 검증 미실시 코드입니다. 메일 서버 주소, 계정 인증 정보, 방화벽 설정에 따라 동작이 달라질 수 있습니다.)*

```python
import os
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication

def send_report_email(summary_text: str, attachment_path: str):
    smtp_server = "smtp.gmail.com"
    smtp_port = 587
    sender_email = os.environ.get("REPORT_SENDER_EMAIL")
    app_password = os.environ.get("REPORT_APP_PASSWORD")
    receiver_email = "manager@example.com"

    if not sender_email or not app_password:
        raise ValueError("환경변수에 발송자 이메일 또는 앱 비밀번호가 설정되지 않았습니다.")

    msg = MIMEMultipart()
    msg["From"] = sender_email
    msg["To"] = receiver_email
    msg["Subject"] = "[정기 보고] 일일 데이터 취합 결과"

    # HTML 본문
    body = f"<p>금일 데이터 취합이 완료되었습니다.</p><p><b>요약:</b> {summary_text}</p>"
    msg.attach(MIMEText(body, "html"))

    # 파일 첨부
    if os.path.exists(attachment_path):
        with open(attachment_path, "rb") as f:
            part = MIMEApplication(f.read(), Name=os.path.basename(attachment_path))
            part["Content-Disposition"] = f'attachment; filename="{os.path.basename(attachment_path)}"'
            msg.attach(part)

    # 발송
    with smtplib.SMTP(smtp_server, smtp_port) as server:
        server.starttls()
        server.login(sender_email, app_password)
        server.send_message(msg)
```

### 5. 무인 자동 실행을 위한 OS 스케줄러 등록

코드가 완성되면 사용자의 운영체제에 맞춰 스케줄러를 등록합니다.

#### Windows (작업 스케줄러 CLI: `schtasks`)
관리자 권한 명령 프롬프트에서 등록합니다. (예: 매일 오전 8시 실행)

```bat
schtasks /create /tn "DailyExcelPipeline" /tr "C:\Python310\python.exe C:\scripts\run.py" /sc daily /st 08:00
```

#### Linux / macOS (`cron`)
터미널에서 `crontab -e`를 실행한 후 아래 라인을 추가합니다.

```bash
0 8 * * * /usr/bin/python3 /home/user/scripts/run.py >> /home/user/scripts/cron.log 2>&1
```

#### 확인 필요 항목
1. **메일 제공자 보안 정책**: 사내 메일 또는 포털 메일(Google, Naver 등) 사용 시 기본 계정 비밀번호가 아닌 '앱 2차 인증 전용 비밀번호' 생성이 필수인지 확인해야 합니다.
2. **파일 권한 및 경로**: Windows 작업 스케줄러나 cron은 실행 위치(`Current Working Directory`)가 스크립트 위치와 다를 수 있으므로 코드 내 경로는 절대 경로로 작성되었는지 점검해야 합니다.
3. **엑셀 원본 서식 일치 여부**: 취합 대상 엑셀의 컬럼명에 공백이나 숨겨진 특수문자가 없는지 사전 스키마 검증 로직이 추가로 필요한지 확인하세요.
