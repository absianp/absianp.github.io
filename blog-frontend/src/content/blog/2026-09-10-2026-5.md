블로그 수익이 줄었다고 글 수부터 늘릴 필요는 없습니다. 방문이 줄었는지, 같은 방문에서도 광고 수익이 달라졌는지에 따라 손볼 일이 다르기 때문입니다. 수익 보고서가 있다면 먼저 같은 기간의 페이지 조회수와 페이지 RPM을 나란히 놓아 봅니다.

## 페이지 조회수와 광고 노출수를 섞지 않습니다

페이지 RPM은 예상 수입을 페이지 조회수로 나누고 1,000을 곱한 값입니다. 광고 RPM은 광고 노출수를 기준으로 계산합니다. 한 페이지에 광고가 여러 개 있으므로 두 지표의 분모는 같지 않습니다. [Google의 RPM 설명](https://support.google.com/adsense/answer/190515?hl=ko)

```text
페이지 RPM = 예상 수입 ÷ 페이지 조회수 × 1,000
예상 수입 = 페이지 조회수 ÷ 1,000 × 페이지 RPM
```

예를 들어 조회수 10,000회, 예상 수입 20달러라면 페이지 RPM은 2달러입니다. 다음 기간의 조회수가 8,000회이고 페이지 RPM이 그대로 2달러라면 예상 수입은 16달러입니다. **계산 설명을 위한 가상 수치이며 이 블로그의 실적이나 수익 예측이 아닙니다.**

조회수가 0이면 RPM을 계산하지 않습니다. 또 애드센스 예상 수입과 확정 수입은 구분해서 기록합니다.

## 한 번에 비교할 기간과 기준을 고정합니다

매일 숫자를 확인하더라도 편집 결정을 할 때는 같은 길이의 기간을 비교하는 편이 낫습니다. 일주일과 한 달의 수입을 나란히 놓거나, 한 번은 모바일만 보고 다음에는 전체 기기를 보면 원인을 찾기 어렵습니다.

| 기록할 항목 | 기록 예시 |
|---|---|
| 기간 | 8월 1일부터 31일, 9월 1일부터 30일처럼 시작·종료일 명시 |
| 측정 도구 | 애드센스, Search Console, 웹 분석 도구를 구분 |
| 분모 | 페이지 조회수인지 광고 노출수인지 명시 |
| 조건 | 전체 기기 또는 모바일 등 같은 필터 유지 |
| 변경 사항 | 제목 수정, 광고 배치 변경, 글 비공개 전환 날짜 |
| 비용 | 도메인·호스팅·이미지·API 등 실제 발생 비용 |

Search Console의 검색 클릭과 웹 분석 도구의 방문 수는 수집 범위가 다릅니다. 서로 정확히 맞추려고 하기보다 각각 같은 도구 안에서 변화를 확인하세요.

## 숫자에 따라 고칠 글을 다르게 고릅니다

**검색 노출이 있지만 클릭이 적은 글**은 먼저 제목과 검색 결과의 설명을 읽습니다. 제목이 본문의 답보다 과장되어 있거나, 질문에 대한 핵심 답이 도입부에 없으면 손볼 여지가 있습니다. 다만 노출 위치와 검색어가 달라져도 클릭률은 변하므로 제목 하나를 원인으로 단정하지 않습니다.

**방문은 있지만 독자의 문제가 해결되지 않는 글**은 예제와 확인 절차를 보완합니다. 설치 글이라면 명령어 다음에 실행 위치와 예상 결과가 있어야 합니다. 제도 안내라면 적용 조건과 공식 확인 경로가 있어야 합니다. 비슷한 글 세 편에 같은 답이 반복된다면 한 편으로 정리할지도 검토합니다.

**조회수는 비슷한데 페이지 RPM이 달라진 경우**에는 같은 기간의 국가·기기·페이지 구성과 광고 상태를 살펴봅니다. 광고 위치를 바꿨다면 날짜를 남겨 비교하되, 계절이나 광고 수요 등 다른 요인도 함께 변할 수 있습니다. 특정 키워드를 넣으면 일정 RPM이 나온다는 식으로 결론 내리지 않습니다.

## 수입에서 운영비를 빼고 남는 작업을 선택합니다

광고 수입과 별도로 지출을 기록합니다. 매달 쓰는 AI API나 이미지 서비스의 비용이 글 한 편을 추가할 때마다 늘어나는지, 고정 구독료인지 구분하면 됩니다.

```text
해당 기간의 운영 잔액 = 실제 수입 − 같은 기간에 인식한 운영비
```

이는 세금 신고용 회계 계산이 아니라 운영 판단을 위한 간단한 기록입니다. 수입이 적은 초기에는 비싼 자동화 기능을 추가하는 것보다 오래된 글의 오류를 바로잡고 운영비를 줄이는 일이 더 나을 수 있습니다.

마지막으로 수정한 URL과 이유를 기록하세요. “SEO 개선”보다 “설치 명령어가 없던 글에 최소 예제와 오류 확인 방법 추가”라고 적어 두면 다음 검토 때 무엇이 달라졌는지 알 수 있습니다. 애드센스 신청 전 콘텐츠 점검은 [사이트 준비 안내](https://support.google.com/adsense/answer/7299563?hl=ko)와 함께 확인할 수 있습니다.
