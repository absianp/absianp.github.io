## 1. pandas와 openpyxl의 서식 처리 차이점

실무에서 `pandas`의 `read_excel()`과 `to_excel()` 함수는 대용량 테이블 데이터를 다루기에 매우 편리합니다. 그러나 `to_excel()`은 DataFrame의 값 데이터를 기준으로 엑셀 XML 구조를 새로 생성하는 방식으로 동작합니다. 이 과정에서 기존 파일에 설정되어 있던 셀 테두리, 배경색, 글꼴, 열 너비, 표시 형식(Number Format) 등의 서식 메타데이터가 모두 기본값으로 초기화됩니다.

반면 `openpyxl`은 엑셀 파일(`.xlsx`)의 XML 구조를 읽고 쓰는 라이브러리입니다. `load_workbook()`을 사용하면 시트 내 셀 데이터뿐만 아니라 `styles.xml`에 저장된 스타일 객체를 메모리에 함께 로드합니다. 따라서 미리 서식을 지정해 둔 템플릿 파일을 열어 데이터를 채워 넣거나, 특정 셀의 스타일 속성을 새 셀에 복제하는 방식으로 원본 디자인을 유지할 수 있습니다.

## 3. 서식 유지 취합 구조: 템플릿 활용과 스타일 복사

취합 결과물의 서식을 온전히 유지하기 위한 가장 안정적인 방법은 **기준 템플릿 파일**을 활용하는 것입니다.

1. 헤더와 샘플 데이터 1행의 서식이 미리 지정된 `template.xlsx`를 준비합니다.
2. 원본 데이터 파일들에서 순수 데이터 값만 추출합니다.
3. 템플릿 시트의 마지막 행 아래에 값을 채우고, 템플릿 기준 행의 스타일 객체(`font`, `border`, `fill`, `alignment`, `number_format`)를 각 셀에 복사합니다.

openpyxl에서는 스타일 객체가 불변(immutable)이거나 참조 형태로 묶여 있으므로, 파이썬 표준 라이브러리의 `copy` 모듈을 이용해 안전하게 복제하는 것이 좋습니다.

## 4. 예외 방지: 빈 행과 날짜 포맷 처리

실무 데이터 파일은 서식이 일정하지 않거나 빈 행, 공백 문자열이 섞여 있어 오류를 유발하기 쉽습니다.

* **임시 파일 필터링:** 엑셀 프로그램이 실행 중일 때 생성되는 `~$파일명.xlsx` 형태의 임시 잠금 파일은 zip 구조가 깨져 있어 `openpyxl.load_workbook()` 호출 시 `InvalidFileException` 또는 `BadZipFile` 에러를 발생시킵니다. 파일 검색 시 파일명이 `~$`로 시작하는 항목을 반드시 제외해야 합니다.
* **빈 행 건너뛰기:** 눈에 보이지 않는 공백 셀이나 `None` 값만으로 구성된 행은 데이터 취합 시 제외해야 합니다. `all(cell.value is None for cell in row)` 조건을 통해 공백 행을 필터링합니다.
* **날짜 및 숫자 포맷:** `datetime` 객체나 특정 숫자 서식이 지정된 셀은 `cell.number_format` 속성까지 함께 복사해야 템플릿 시트에서 날짜가 정수 시리얼 넘버로 표시되는 현상을 막을 수 있습니다.

## 5. 자동 탐색 및 날짜별 백업 스크립트 예제

아래 스크립트는 지정된 폴더에서 `.xlsx` 파일을 탐색하여 템플릿 서식을 유지하며 취합하고, 타임스탬프를 적용한 파일명으로 백업 저장하는 전체 구조입니다.

```python
# [실행 검증 미실시 예제 코드]
import os
import shutil
from copy import copy
from datetime import datetime
from pathlib import Path
from openpyxl import load_workbook


def copy_cell_style(source_cell, target_cell):
    """원본 셀의 서식(글꼴, 테두리, 채우기, 정렬, 표시형식)을 대상 셀로 복사합니다."""
    if source_cell.has_style:
        target_cell.font = copy(source_cell.font)
        target_cell.border = copy(source_cell.border)
        target_cell.fill = copy(source_cell.fill)
        target_cell.number_format = copy(source_cell.number_format)
        target_cell.protection = copy(source_cell.protection)
        target_cell.alignment = copy(source_cell.alignment)


def merge_excel_files(source_dir: str, template_path: str, output_dir: str):
    src_path = Path(source_dir)
    out_path = Path(output_dir)
    out_path.mkdir(parents=True, exist_ok=True)

    # 1. 템플릿 로드
    wb_template = load_workbook(template_path)
    ws_template = wb_template.active

    # 템플릿의 2번째 행을 서식 기준 행으로 참조 (1행은 헤더 가정)
    style_row_idx = 2
    max_template_col = ws_template.max_column
    target_row_idx = ws_template.max_row + 1

    # 2. 대상 폴더 내 엑셀 파일 탐색 (~$ 임시 파일 제외)
    file_list = [
        p for p in src_path.glob("*.xlsx") 
        if not p.name.startswith("~$") and p.resolve() != Path(template_path).resolve()
    ]

    if not file_list:
        print("취합할 엑셀 파일이 존재하지 않습니다.")
        return

    print(f"총 {len(file_list)}개의 파일을 탐색했습니다.")

    for file_p in file_list:
        print(f"처리 중: {file_p.name}")
        # 수식 계산 결과값을 가져오기 위해 data_only=True 설정
        wb_src = load_workbook(file_p, data_only=True)
        ws_src = wb_src.active

        # 헤더를 제외한 2행부터 데이터 읽기
        for row in ws_src.iter_rows(min_row=2, values_only=True):
            # 행 전체가 None인 경우 건너뛰기
            if all(val is None for val in row):
                continue

            for col_idx, val in enumerate(row[:max_template_col], start=1):
                target_cell = ws_template.cell(row=target_row_idx, column=col_idx, value=val)
                
                # 기준 서식 행의 해당 열 셀 스타일 복사
                ref_style_cell = ws_template.cell(row=style_row_idx, column=col_idx)
                copy_cell_style(ref_style_cell, target_cell)

            target_row_idx += 1

        wb_src.close()

    # 3. 날짜별 백업 파일명 생성 및 저장
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    output_filename = f"취합결과_{timestamp}.xlsx"
    final_save_path = out_path / output_filename

    wb_template.save(final_save_path)
    wb_template.close()
    print(f"취합 완료 및 저장 완료: {final_save_path}")


if __name__ == "__main__":
    # 작업 경로 설정 (사용자 환경에 맞게 수정 필요)
    SOURCE_DIRECTORY = "./data_input"
    TEMPLATE_FILE = "./templates/template.xlsx"
    OUTPUT_DIRECTORY = "./data_output"

    # 폴더가 없을 경우 예비 생성 안내 또는 스크립트 실행
    if os.path.exists(TEMPLATE_FILE):
        merge_excel_files(SOURCE_DIRECTORY, TEMPLATE_FILE, OUTPUT_DIRECTORY)
    else:
        print(f"템플릿 파일을 찾을 수 없습니다: {TEMPLATE_FILE}")
```

## 6. 주요 오류 대처 및 운영 주의사항

| 오류 및 현상 | 원인 | 해결 방법 |
| :--- | :--- | :--- |
| `BadZipFile: File is not a zip file` | 엑셀 열림 상태의 `~$` 임시 파일 로드 시도 | 파일 탐색 조건에 `not filename.startswith('~$')` 필터 적용 |
| 수식 셀의 값이 `None`으로 출력됨 | `data_only=True` 로드 시 엑셀에서 계산된 캐시가 없음 | 엑셀 프로그램에서 파일을 열어 저장한 후 재시도하거나 `data_only=False`로 수식 문자열 로드 검토 |
| 날짜 셀이 45000 등 정수로 표기됨 | `number_format` 속성이 누락됨 | 스타일 복사 시 `target_cell.number_format = copy(ref_cell.number_format)` 명시 |

## 7. 출처 및 확인 필요 사항

* **참고 공식 출처:**
  * [openpyxl 공식 문서 (openpyxl.readthedocs.io)](https://openpyxl.readthedocs.io/)
* **확인 필요 사항:**
  * **대용량 파일 성능 검토:** 수십만 행 이상의 대용량 파일을 처리할 경우 `openpyxl`의 메모리 점유율이 높아질 수 있습니다. 이 경우 스타일 유지가 제한되는 `read_only=True` 또는 `write_only=True` 모드 적용을 검토해야 합니다.
  * **셀 병합(Merged Cells) 구조:** 원본 데이터 영역에 병합된 셀이 포함되어 있을 경우 단순 행 복사 시 좌표 충돌이 발생할 수 있으므로 사전에 데이터 구조를 정규화해야 합니다.
